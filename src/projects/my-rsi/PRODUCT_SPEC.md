# my-rsi

Indicateur RSI avec alertes

## Résumé
Indicateur de trading multi-plateforme généré avec Trading Indicator Factory

## Cas d'usage
- Détection de signaux de trading
- Confirmation de tendance
- Identification de retournements

## Paramètres
| Nom | Type | Défaut | Plage | Description |
|-----|------|--------|-------|-------------|
| period | int | 14 | 2-100 | Période de calcul |
| applied_price | enum | close | open/high/low/close | Prix utilisé |
