# Installation Guide

## Prérequis

- MetaTrader 5 (Build 3320+)
- MetaTrader 4 (Build 600+)
- TradingView (compte gratuit)
- NinjaTrader 8 ou 9

## Installation MetaTrader 5

1. Ouvrir MetaEditor
2. Fichier → Ouvrir un fichier
3. Naviguer vers `mt5/[indicateur].mq5`
4. Compiler (F7)
5. Navigateur MT5 → Indicateurs personnalisés

## Installation MetaTrader 4

1. Ouvrir MetaEditor
2. Fichier → Ouvrir un fichier
3. Naviguer vers `mt4/[indicateur].mq4`
4. Compiler (F7)
5. Navigator MT4 → Indicateurs personnalisés

## Installation TradingView

1. Ouvrir Pine Editor
2. Nouveau → Nouveau script Pine
3. Coller le contenu de `pine/[indicateur].pine`
4. Sauvegarder et ajouter au graphique

## Installation NinjaTrader

1. Ouvrir NinjaTrader
2. Tools → Import → NinjaScript Add-On
3. Sélectionner `ninjatrader/[indicateur].cs`
4. Compiler
5. Indicateur disponible dans les indicateurs personnalisés
